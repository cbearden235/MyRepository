Modern HTTP

HTTP/1.1

This version contributed several improvements including reusing connections. Before, every time a new request was sent to a server, a new connection would be created. This took time, but reusing the same connecting between a client and server was implemented. Another improvement was pipelining. This made it so that subsequent requests could be sent out over the network before previous requests had finished transmitting. Servers also started sending responses in chunks. These improvements all increased the speed of the transmissions.

HTTP/2

Communication continued to speed up by allowing requests and responses to be fully multiplex. This means that different responses and requests could use the same connections which saved time because new connections did not have to be created. This version also compressed HTTP header fields to reduce the protocol overhead.

HTTPS

HTTPS, which stands for Hypertext Transfer Protocol Secure, uses an encryption protocol called Transport Layer Security (TLC) to keep the information that is being sent over the network secure. A lot of the information that is sent is sensitive, personal information, and it is important to keep it private. HTTPS is used by most websites today.
