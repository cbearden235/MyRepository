Early HTTP

HTTP/0.9

This was the initial version of HTTP which was created by Tim Berners-Lee. The requests and the responses that were sent were very simple. The requests were just one line and the responses where just the files themselves. They did not have headers, which are now used to convey additional information. HTTP/0.9 also lacked error and status codes. Instead, a special HTML file was sent to tell the user what had happened.

HTTP/1.0

During this stage of the evolution the browsers and servers led the way. The status code was added which was placed at the beginning of responses servers sent. This made it so that the client was able to understand what happened if an error occured instead of the user having to figure it out. The client was then able to respond to the error.
