All About HTTP

Introduction

Hypertext Transfer Protocal (HTTP) is a protocol for how devices send and receive resources over networks. This is how all the information on the websites we look at every day is sent to our computers. HTTP sends information such as Hypertext Markup Language documents, images, and videos to web browsers. It also sends content back to the servers that have web pages. HTTP is an important part of how we use and communicate over networks.

Key Terms

Term Definition
HTML Hypertext Markup Language which is the standard system for creating files which are used to for displaying web pages
Client A device or computer program (often a web browser) which sends requests and recieves resources and services from a server
Server A device or computer program which recieves requests and provides resources and services to a client
Pipelining A system of organizing tasks in stages which allows multiple taks to be complete at the same time
Multiplexing A sytem of combining messages sent over a network which allows multiple message to be sent simultaneously which allows for sharing of resources
Overhead Additional resources that a system uses which are not required for the system to run
